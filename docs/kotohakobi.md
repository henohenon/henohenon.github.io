# コトハコビ
## アイコン
- ロゴを改良したハコSVG
  - 最初は単なる□
- 💭ではなく、荷物タグ
- ホバーでフタが開いてコが顔を出す
- クリックでコが飛び出てアイコン完成
  - ハコ自体もちょっとビクンってなる
- ホバー時から例の音が鳴る

## メイン
- 荷物一覧画面を移植
  - 開いたら荷物一覧の音になる
  - 音に合わせていくつかハコが出てくる。ハコにホバーで中身が見える
- 画面比率を遵守！
