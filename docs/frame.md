# サイト概要
ここでは、本サイトのあら回しについて記述する。

## 用語整理
### Gallery
展示品がある場所。
### Focus
展示一つを集中してみる場所。
### Introduction
導入。最初の展示品。
### Exhibit
Icon+キャプション一式の展示品。
### Icon
Galleryにおける、作品本体。作品そのものやロゴを貼るのではなく、適切に抽象化した概念。

## 構造
indexの構造は次の通り。
```xml
<body>
  <header />
  <introduction>
    <icon />
    <text-caption />
  </introduction>
  <gallery>
    <exhibit>
      <icon />
      <title-caption />
    </exhibit>
    <exhibit>
      <icon />
      <title-caption />
    </exhibit>
    ...
  </gallery>
  <footer />
</body>
```

各Exhibitをクリックすると、対応するFocusに遷移する。
Focusの構造は次の通り。
```xml
<body>
  <details-caption />
  <main />
  <title-caption />
</body>
```
画面遷移時のトランジションこそが本サイトの体験のキモである。

introductionのみ、focusではなくemanationとなる。詳しくは、./henohenon.md。

## 情報整理
### Gallery
- タイトル
  - 作品名
  - 番号
- 作品
  - ミニチュア
  - 吹き出し
### Focus
- 作品
  - リンクボタン
  - 写真など紹介要素
- 詳細キャプション
  - 閉じるボタン
  - コンセプト・短文の説明
  - 自分の作業
  - 使用技術
  - Moreボタン
- タイトルキャプション
  - 作品名
  - 番号

## 演出
### Gallery Icon
- 一覧として適切な解像度、アイコンとして適切な抽象度
- 押したくなる強調
  - 吹き出しなど
- 遊び心
  - ホバー時のリアクション(スマホの場合は該当要素が画面中央時)
  - クリック時のリアクション(トランジションと絡めてもよし別でもよし)
  - 自由であること

### Focus
- リンクボタンが主役
- 概要、タイトル表示は固定
- 基本スクロールもクリックもナシ。何もしなくても完成している状態。
- 世界観がミニマルに伝わる。体験したくなる。

## トランジション
- 凝って凝ってこだわりまくる。
  - ワクワクすること
  - 長すぎないこと
  - 戻る用も用意(逆再生でも可)

## ヘッダー
右上にAboutがある。これはindexの、イントロダクションを経過したときのみみられる。fixed。

## フッター
一番下にある単に著作権表示のみのシンプルなフッター。indexでのみ見られる。
一応Xのリンクを貼る
