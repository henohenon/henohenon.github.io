## 議論で決めたこと

### 表現の手段は ③ 方向性 + 自由 (Mode 3) + α

「① メニュー型 / ② 野放し / ③ 方向性 + 自由」の 3 択。direction.md の精神 (縛り撤廃 / 補助で質上げる) と整合するのは ③ 一択、と確認。

「基本自由 + 適切な assist」という温度感を direction.md の脚注的に書く方向。

### Identity と Dress の分離 (direction.md 前提に追加)

「最悪ヘッダーとか取っ払えるほどの自由度を与えるか、それともテンプレから選ぶか」という問いから、線引きを明確化:

- **HTML 骨格 (Astro)** = Identity = Claude 不可侵 (戻る場所感の源泉)
- **CSS (theme.css)** = Dress = Mode 3 全自由
- **JS** = 当面禁止、ただし静的 bridge (`--mx --my` / `--tod`) は適切性で判断、`fetch` 系は除く
- **Astro components** = Identity の一部、不可侵

宣言的 (CSS) と命令的 (JS) の境は実装上明確で、感覚的な線引きではない。

### レイアウトは concept-first hybrid

「テンプレ複数化 (BaseMagazine 等) でいくか、Mode 3 全自由か」を悩んだ末、hybrid に着地:

```
1. Claude が今日の曲を読む
2. concept を文字列で書く (P1 concept-first)
3. layout-patterns.md を眺める
4. 判断:
   a. concept が合致するパターンがあれば → 使う
   b. 部分一致 → パターンを base に拡張・改変
   c. どれにも合致しない → 自由に書く
5. 配色 / typography / 装飾を自由に乗せる
```

(旧 F2「テンプレ複数化」は撤回。)

### フォントは Mode 1 不可避

「物理アセット制約から、フォントだけは Mode 1 (メニュー型)」を受容。OFL ライセンスの日本語フォント 15-20 個を curation して bundle、subset 化、`@font-face` で `--font-*` 変数を提供する方針。

### 棚上げ装飾の純 CSS 組を復活

Tier 4 おもちゃ系のうち、純 CSS で書けるものを復活:

- ロゴクリックで弾む (`:active` + transform)
- 隠しキャラ (`:hover` / `:target`)
- 隠しテーマ (`:target` で URL fragment 駆動)
- マウス trail (C2 cursor bridge 後、部分的に)
- scroll-driven animation (CSS Baseline)
- `@starting-style` ロード時演出 (CSS Baseline)

JS / 状態管理が必要なもの (マウス停止演出、ブックマーク) は当面棚上げ継続、ただし **JS 制限の re-visit を将来候補に** ( `fetch` は除く)。

### 表現の周辺判断

- `prefers-reduced-motion: reduce` — 必須 (SYSTEM_PROMPT で既に強制)
- `prefers-color-scheme` (light/dark) — 無視 (今日のテーマが OS 設定より勝つ)
- `prefers-contrast` — Claude 任意
- レスポンシブ — モダンに (clamp / container query / logical / text-wrap)
- markdown 要素のスタイリング — Claude 任せ
- RSS — 追加候補 (記事のみ feed)
- print — 無視
- 多言語 — ja only
