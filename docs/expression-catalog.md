# 表現方法・レイアウト カタログ

毎日のテーマ生成で使う/使わない手段の一覧。新しい候補を思いついたらここに追記して、
方針が決まったら採否を更新する。

> **重要**: 「採用」マークの手段でも **詰め込み禁止**。Claude が今日の曲に合うと判断した
> 時だけ使う。何も使わない日があっていい (「静けさも表現」)。詳細は
> [decisions.md "適切性ファースト"](decisions.md)。

## ステータス凡例

| 記号 | 意味 |
|---|---|
| ✅ | **採用** — 実装する / 実装済 (TODO.md #3 / #7 で追跡) |
| 🟡 | **棚上げ** — 何か trigger があれば再検討 |
| 🔄 | **グレー** — 要相談 |
| ❌ | **却下** — UX / 複雑度 / 儚さ原則に反する |

## 7. カーソル / マイクロインタラクション (おもちゃ系)

ユーザーが好み。Tier 1-3 は採用、Tier 4 は規模感が許せば。

### Tier 1: CSS のみ・hover 範囲

| 手段 | 状態 |
|---|---|
| リンク hover で要素自体に微反応 (傾く / 浮く / 色変 / 影伸びる) | ✅ |
| リンクの下線が左→右にスーッと引かれる | ✅ |
| リンク末尾の `→` が hover で右にチョッ | ✅ |
| ロゴ / ブランドマーク hover 反応 (傾く / 色変) | ✅ |
| フォーカス枠の意匠 (波線 / 二重) | ✅ |
| 段落 hover でハイライト | ✅ |
| スクロール上部の読了バー (CSS scroll-driven は別、ここは JS) | 🔄 (機構との兼ね合い) |

### Tier 2: 静的カスタムカーソル

| 手段 | 状態 |
|---|---|
| カスタムカーソル形状 (`cursor: url(...)`) | ✅ |
| 要素別カーソル切替 (リンクで `crosshair` / 本文で `text` 等) | ✅ |
| リンク hover で `cursor: grab` / `help` / SVG 等の遊び | ✅ |

### Tier 3: カーソル位置 CSS 変数 bridge (要 5 行 JS)

機構: `mousemove` で `--mx` / `--my` を `:root` に書く小スクリプト常設 → Claude が
CSS で自由に演出。

| 手段 | 状態 |
|---|---|
| `mix-blend-mode: difference` カーソルスポット | ✅ |
| カーソル追従の小アイコン (`position: fixed; left: var(--mx)`) | ✅ |
| カーソル軌跡 (trail) | ✅ |
| 見出しがカーソル方向にちょい傾く (軽パララックス) | ✅ |
| spotlight (radial-gradient + カーソル位置) | ✅ |

### Tier 4: おもちゃ (棚上げ — 規模感が許せば再開)

| 手段 | 状態 | 備考 |
|---|---|---|
| ロゴクリックで小さく弾む | 🟡 | CSS animation 1回 |
| マウス停止 N 秒で背景に何か | 🟡 | タイマー JS |
| 画面隅に小キャラ (静的、毎日違う位置) | 🟡 | 配置ロジック要 |
| 特定キーで隠しテーマ | 🟡 | キャッシュ・状態管理発生 |
| リンク通過で trail | 🟡 | Tier 3 trail と類似 |
| 段落クリックでブックマーク (`localStorage`) | 🟡 | 状態管理発生 |
