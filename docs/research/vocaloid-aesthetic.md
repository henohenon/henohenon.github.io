# Vocaloid 文化の視覚語彙

> 本プロジェクト固有の語彙集。曲のジャンル / シーン / 投稿者文化が
> どんなビジュアル系統を引き出すか。
> 「曲を信じる」プロンプトを支える文脈知識として。

---

## 1. 歴史的バックグラウンド (要約)

- **2004** — Yamaha が Vocaloid (歌唱合成エンジン) を発表
- **2007.08** — 初音ミク (Crypton) 発売、Nico Nico Douga と同年launch
- **2007 末-2008** — メルト (ryo, supercell) / みくみくにしてあげる など bench mark
- **2009-2011** — ボカロ全盛、ryo / wowaka / kemu / じん など producer 時代
- **2012-2014** — 第2世代 (DECO\*27, ハチ (米津玄師), n-buna)
- **2015-2018** — 商業との接続強まる、ボカロ→歌い手→アーティストの導線確立
- **2019-2022** — Project SEKAI 等のゲーム連動、世代継承
- **2023-2026** — Magical Mirai、世界進出継続、シーンは細分化と循環を続ける

### Nico Nico Douga 文化の重要性
- 「動画 + コメント弾幕」というネット文化の発祥地
- Vocaloid 楽曲は **音 + 映像 + 歌詞 + コメント** の 4 重奏で受容される
- 「動画」必須文化 → 視覚表現が音楽と切り離せない
- ランキング (Hall of Fame / Legend / Myths) で正典化される独自基準

---

## 2. 視覚文化の特徴 (genre 横断)

### MMD (MikuMikuDance)
- 樋口優が公開したフリー 3D アニメーションソフト
- 低スキルでも 3D ダンス動画が作れる革命
- 視覚的に **整然とした 3D** + **手作り感** の混在が特徴
- 「○○ Original Motion」「○○ Stage」など素材の二次配布文化

### Pixiv (イラスト文化)
- ボカロ二次創作の主戦場、膨大な fan art アーカイブ
- 一次作品 (曲) → 二次 (イラスト) → 三次 (踊ってみた / 歌ってみた) の流通
- イラストレーター個人がスター化 (米津玄師の初期、れるりりの絵、etc.)

### 楽曲動画スタイル
- **イラスト 1 枚 + 歌詞表示**: 古典スタイル、minimalist
- **アニメーション動画**: わたあめ系、しっかりアニメ系
- **ノイズ系 / グリッチ系**: シリアス曲 / 鬱曲で多用
- **白背景 + 黒文字 + アクセント色**: 詩的 / 静かな曲
- **MMD 動画**: ダンス + 3D 演出

## 3. ジャンル別の "視覚言語"

### 王道ポップ / 元気
- 例: メルト, テトリス, 千本桜, シャルル
- 色: 鮮やか pastel + 高彩度
- 文字: 丸い / ポップ / 太め
- 雰囲気: kawaii + 力強さ

### ボカロロック (wowaka 系列)
- 例: ローリンガール, アンノウン・マザーグース, 砂の惑星
- 色: 鋭い 2-3 色 (赤+黒+白、青+黒)
- 文字: アシッド / グリッチ / 詰めた配置
- 雰囲気: 不安定、せきたてる、文学的

### 鬱ボカロ / 病み系
- 例: ロストワンの号哭, ヒバナ, ベノム
- 色: 暗色基調 + 1 蛍光色 / モノトーン
- 文字: 細い serif / 詰め / 縦書き
- 雰囲気: 内向き、痛み、囁き

### エレクトロ / Future Bass / EDM
- 例: テオ, ヴァンパイア, ロキ
- 色: neon (cyan / magenta / yellow)
- 文字: mono / pixel / glitch
- 雰囲気: 未来的、機械的、高速

### バラード / 静かな曲
- 例: 桜ノ雨, 千年の独奏歌
- 色: パステル単色 / 水墨
- 文字: 明朝 / 行間広 / 余白多
- 雰囲気: ノスタルジック、内省

### 物語性 (ストーリー曲)
- 例: 悪ノ召使い, カゲロウデイズ, 文学少年
- 色: テーマカラー (赤と緑、青と黄など物語シンボル)
- 文字: 装飾 serif / display
- 雰囲気: 章番号、書物的、heritage

### ネタ曲 / 内輪曲
- 例: ぽっぴっぽー, スイートマジック
- 色: 過剰 / 高彩度 / 全部入り
- 文字: 漫画調 / コミック / 太め
- 雰囲気: ユーモア、軽さ

### 和風 / 民謡寄り
- 例: 千本桜, 六兆年と一夜物語, ゴーストルール
- 色: 朱 / 紺 / 金 / 墨
- 文字: 明朝 + 縦書き / 江戸文字
- 雰囲気: 和柄、千代紙、季節感

## 5. 反復するモチーフ

- **ねぎ** — ミク = ねぎの連想 (派生: 派生作品で頻出)
- **桜** — 桜ノ雨 / 千本桜 / 桜降る代に決闘を 等で繰り返される春モチーフ
- **電子音 / 機械** — Vocaloid 本来 = 合成音、サイバーパンク連想
- **マイク / ヘッドホン** — 音楽ジャンルの本籍
- **学校 / 制服** — 鏡音 / カゲプロ系 / 青春モチーフ
- **空 / 海 / 月** — 抒情的曲で頻出
- **時計 / 歯車** — 時間モチーフ (千年の独奏歌 等)
- **書物 / インク** — 物語性のある曲
- **ガラス / 鏡** — 内省 / 鬱

## 6. ボカロ作品の言語的特徴 (デザインに翻訳できる要素)

- **タイトル**: 漢字熟語 / カタカナ / 英字 / 記号混在 (`」、）` 等の使用も)
- **歌詞**: 比喩多用、文語混在、ひらがなで詰める、抽象的キーワード
- **キーワード**: 「夜」「明日」「君と僕」「一人」「機械」「天才」「世界」など頻出
- **メタ的言及**: 「歌う」「声」「言葉」自体への自己言及が多い

これらを Claude が読んで:
- 比喩の多さ → 装飾度高め
- 文語混在 → serif / 縦書きの引き出し
- 機械系キーワード → mono / cyber 系
- 内省キーワード → minimalist / 静かなレイアウト

への翻訳が成立する。

---

## 7. シーン特有の文脈 (誤読リスク注意)

- **作詞作曲歌唱が分業**: ボカロは "歌い手 ≠ 作曲者" の構造、Claude が author を取り違えないように
- **二次創作前提文化**: シーン全体が「派生を生む」前提で動いてる
- **「P (プロデューサー)」呼称**: 作曲者を "○○P" と呼ぶ習慣 (kemuP, wowakaP, etc.)
- **ニコ動 vs YouTube vs SoundCloud**: 投稿先によりカルチャーが微妙に違う
- **同人音楽との接続**: 東方 / アイマス / 同人 CD カルチャーと近接
- **商業との関係**: ボカロ出身プロデューサーが商業に流れる流れが定常 (米津、Eve、ヨルシカ、ずっと真夜中でいいのに、ado etc.)

## 8. このプロジェクトでの活用

### Claude に渡せる "翻訳ヒント"
- 曲のタイトル + ボーカル名から、上の表を引き出して **キャラ色 / ジャンル系統** を反映
- 歌詞のキーワードから **モチーフ** を抽出し装飾に反映
- ジャンル別 "視覚言語" を **system prompt の引き出し** として持つ

### prompt 改善案 (将来の補助情報フェーズ)
```
今日の曲: ローリンガール / wowaka feat. 初音ミク
ボーカル: 初音ミク (default color: turquoise #39C5BB)
ジャンル傾向 (推測): ボカロロック (wowaka 系)
  → 視覚語彙の引き出し: 鋭い 2-3 色 / アシッド / 詰めたタイポ / 不安定さ
```

ただし**Claude を縛らない** こと。あくまで引き出しのヒント、決定権は Claude (適切性ファースト)。
