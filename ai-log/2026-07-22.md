## トランジション方針（議論メモ・spec 未反映）
- 「ハッシュルーター＋DOM 差し替え」でルーティング手段としては妥当。パフォーマンスは 3 展示規模では論点にならない。
- 「View Transitions がスマホで効かない」という前提は 2026 時点では古め。**iOS Safari 18（2024/9）・Android Chrome とも対応**。非対応は古い端末の裾野のみ。VT は非対応時に「アニメ無しで即差し替え」に自動フォールバックする設計（サイトは壊れない）。
  - ※対応状況は記憶ベース。依存を決める前に caniuse で最新確認が望ましい。
- ただし演出がサイトの「キモ」なので、即差し替えフォールバックだと非対応端末で体験が丸ごと消えるのが惜しい。→ **役割で二段構え**にする方針で合意:
  - **劇場型の派手な演出（ワープ / 幕の開閉 / ハコの飛び出し）** … VT に依存しない**自前オーバーレイ**（CSS / Web Animations）。**全端末で動く**。作り込みも自由。
  - **共有要素モーフ（Gallery Icon → Focus への連続移動）** … **View Transitions を対応環境でのみ enhancement**。非対応ならモーフだけ省略、オーバーレイ演出は残るので体験は保たれる。
  - VT 一本足には**しない**。
- この方針は本人判断で **spec-and-plan.md への反映は見送り**（ログにのみ記録）。

## スタック再検討 → Svelte へ切替（経緯）
Phase 1 の diff を Zed でレビュー中に本人から違和感。3 点が顕在化:
1. `views.ts` の**文字列テンプレート＋手動エスケープ**の記述性が悪い（→ component で書きたい）。
2. **ハッシュルーティングは Pages に載せるための妥協**で必然性が薄い（→ 素のクリーンパスにしたい）。
3. 本サイトの核心はトランジション。**DOM を保持したまま遷移する SPA 的アプローチ**が向く。

検討の流れ:
- **Astro** も候補に（旧サイトで使用実績）。静的プリレンダでクリーンパス、ClientRouter で VT 標準対応と好相性。ただし MPA 基盤なので「消えない常駐要素／連続する世界」を強く求めると `transition:persist` 等でやや窮屈になりうる、という分岐を確認。
- トランジション連続性を優先し **SPA 的アプローチ**へ傾く。
- 発想の整理: この用途は「UI フレームワーク」より「**トランジション/アニメエンジン**」の選択が主役。UI 側は *DOM を壊さず enter/exit を寄越す* ならよく、**シェーダは常に canvas＋rAF＋GLSL でフレームワーク非依存**。→ 器（ビュー/ルーター）と演出（エンジン）を分離して考える。
- 器の最終候補は **Svelte vs Solid**（自作マイクロ層も俎上に）。
  - **Solid**: JSX(TSX)＋signals（uniform 供給に good）。ただしトランジションは自前寄り。
  - **Svelte**: `transition:`/`animate:`(FLIP)/**`crossfade`（共有要素モーフ）**が言語ビルトイン。**トランジションが主役**の本件で有利。Svelte 5 runes で反応性も担保。宣言的 WebGL は **Threlte** が成熟。
  - **自作**: ポートフォリオのブランド（手書き志向）とは合うが、リアクティビティ自作の罠がある。要不要の分岐は「各ルートが基本静的か（＝反応性不要）」。
- **結論: Svelte を採用**（本人合意）。シェーダ欲は canvas 島＋GLSL で問題なく満たせる。

### これに伴う spec 改定（`spec-and-plan.md` §7・§9）
- フレームワーク: 導入せず（バニラ）→ **Svelte（Svelte 5）**。
- 器: ハッシュルーター → **SvelteKit ＋ `adapter-static`**（静的プリレンダのクリーンパス、base=`/`）。
- 遷移: ハッシュ＋View Transitions 一本 → **SPA ナビゲーションで DOM 保持**＋Svelte transitions（`crossfade`/FLIP）＋必要に応じ GSAP、シェーダは常駐 canvas 島。

## ルート遷移演出（View Transitions）
体験のキモ。ここからはフェーズ厳密より微調整ベースで進める方針に切替。

- **方式**: SvelteKit `onNavigate` + `document.startViewTransition`。非対応ブラウザは即時遷移にフォールバック（芯の遷移・戻り・中央寄せは全環境で動作、演出だけ enhancement）。
- **共有要素モーフ**: title-caption に作品ごとの `view-transition-name`（`title-<id>`）を付与し、Gallery↔Focus で同要素が移動。Focus では `transform: scale(1.5)`（em 実サイズ版も試したが、静止時のキレ差は体感できず・モーフ純度で transform が勝るため transform 採用）。
- **dive/rise ズーム**: Gallery→Focus は index 全体をクリック Icon 中心に拡大フェード、Focus→Gallery は逆。原点は CSS 変数 `--vt-x/--vt-y`。
- **「1枚だけモーフ」制御**: 全タイトルに名前があると非対象がその場でフェードしてしまうため、対象1枚だけ名前を残し他は一時 `none`（root ズームに含める）→ 遷移後に復元。
- **詳細キャプション**: `view-transition-name: details` で `blur→くっきり` の「にじみ出る」入場。
- **Introduction↔About**: 顔タイポに `view-transition-name: face`。index↔about で顔が残って周囲が入替。dive/rise 時だけ名前を外して root ズームに含める。
- **戻り導線**: Focus の × を `{元Galleryルート}#{id}` に（`nav.svelte.ts` で from を保持）。戻り先で該当カードを中央スクロール（`afterNavigate` + rise 時に原点も再アンカー）。Exhibit に実 `id` を付与（プリレンダのフラグメント検証 & 非 VT 時のフォールバック）。
- **About カードにも ×**（Home へ）。`.close` を `.caption-card .close` に一般化して Focus と共通化。
- **コード整理**: 遷移ロジックを `src/lib/transition.ts` に集約。コンポーネントは `onNavigate(routeTransition)` / `afterNavigate(centerHashExhibit)` / `onclick=markExhibitOrigin` を繋ぐだけに。`onNavigate` の Promise ハンドシェイクは `Promise.withResolvers()` で平坦化。

### メモ（env）
- imperative な DOM 操作（`style.setProperty` 等）は最も枯れた API で env リスクなし。env 依存は View Transitions のみ（要 caniuse 確認: Chrome 111+/Safari 18+/Firefox 139+）で、ガード済み。
- `Promise.withResolvers` は Chrome 119+/Safari 17.4+ と VT より少し新しい（Chrome 111-118 の隙間あり）が、実害ほぼ無しと判断し採用。

## クリック判定・戻り導線・遷移の微調整
- **判定を要素単位に**: 「余った領域全体がクリック可能」をやめ、意味のある要素だけをリンクに。
  - 顔: `.face-area`（中央寄せ・非リンク）と `.face-link`（顔＋少し padding の判定）に分離。
  - Exhibit: `<a class="exhibit">` をやめ、**Icon と Title をそれぞれ別リンク**（`.icon-link` / `.title-link`）に。カード全体判定は廃止。ズーム原点は `closest('.exhibit')` の Icon に統一。
- **戻り導線を増やす**: Focus は ×・タイトルの両方から `{元Galleryルート}#{id}` へ。About は ×・caption（00 へのへのん）から Home へ。**About の顔はリンクにしない**（重複回避、顔は index→About 専用）。
- **スクロール保持**: index↔about の遷移リンクに `data-sveltekit-noscroll`（顔/ヘッダー About/About caption/About ×）。切替でスクロール位置が戻らない。gallery↔focus とは別ロジックと割り切り（実際 index↔about は JS ほぼ無し＝既定 VT＋CSS 顔モーフ）。
- **にじみ出るを共通化**: About 右上カードにブラー遷移が無かったのは `view-transition-name` 未設定で root クロスフェードだったため。`.intro-links` に `about-caption` を付け、seep アニメを `details` と共通化（keyframes を `card-seep-*`、セレクタをカンマ共有）。
- **Gallery タイトルは 0.7 倍**（Focus 等倍を基準）。「focus 拡大」→「gallery 縮小」に発想転換。モーフは 0.7→1.0。
